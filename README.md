# XSLT-Transformer

### 🖥️ Get Started

| Platform | Recommended |
|---|---|
| **Windows** | [Download XSLT-Transformer.exe](XSLT-Transformer.exe) |
| **Linux / macOS** | See [Source Code](#-run-from-source) below |

---

## ⚡ Run from Source
*Works on Windows, Linux, and macOS.*

1. **Install Dependencies**:
   ```bash
   pip install lxml customtkinter
   ```
   *(Linux users may need: `sudo apt install python3-pip`)*

2. **Run Application**:
   ```bash
   python transformar.py
   ```

---

## 📖 How to Use

1. **Select Files**: Pick your `.xml` and `.xsl`.
2. **Output**: Choose where to save the result.
3. **Transform**: Click the **⚡ Transform** button.
4. **View**: Open the generated file in your browser.
